# Member information requirements

Keep three separate commands: `/info-clan {clan}` for profiles, `/info-member {clan}` for rosters and `/info-player {nick}` for individual ranking searches. `/info-member` accepts only an optional configured `clan`, using the default if omitted. It presents all members, 10–20 per page, total count, rank information and requester-only navigation. Buttons disable at boundaries and expiration; stale interactions direct users to run `/info-member` again. Remove the old nickname option from `/info-member`.

Sort the entire roster by the numeric suffix of each validated original `rank_<number>.png` asset from highest to lowest before pagination. These are the same numbers used in `pb_rank_<number>` emoji names. Equal ranks retain website order; missing or untrusted rank images come last in website order. Sorting must work even when emojis cannot be prepared and must preserve all member identities.

Each roster row places the member's actual website rank image before the bold nickname: `1. [rank icon] **nickname**`. Use application emojis for inline images, reusing existing icons and preparing missing ones automatically. Preserve original icon associations; the example `rank_41.png` does not replace other members' actual ranks. Fall back to an original-image link if emoji preparation fails, and Rank N/A if no image exists.

`/info-player` accepts only a required `nick`. Request HTML from `/ranking/individual` using fixed `termtype=3` and the unchanged nickname as `keyword`. Search any player without fetching a clan roster. Use an exact case-sensitive match first, otherwise a unique case-insensitive match among returned rows. Preserve nickname punctuation, Unicode, spaces and original case. Never use substring or approximate matching; a missing character produces a readable not-found response.

Read each `.nrank_table > .r_tr`: `.r_td.win` is the game's ranking position; `.r_td.name > a[data-env][data-nick]` provides the exact nickname and identifier; `.r_td.rank > .txt` provides the rank name and original `.rank_img img`; `.r_td.exp > .txt` supplies the search EXP. After selecting a player, use only that row's exact data-env for GET `/clan/detail?div=1&env=...`. Decode percent encoding once at the HTTP boundary and serialize through URLSearchParams. Never guess an identifier or infer a rank name from its image number or JSON Rank.

Use the nickname as the embed title and the original rank image as its thumbnail. Group the requested statistics into two full-width sections. Player Info shows Game Ranking and Rank from the HTML, Total EXP from JSON Exp, Kill from Kill, Death from Death, Kill/Death Ratio, Headshot from Headshot and Headshot Ratio. K/D is kills/deaths; headshot ratio is headshots/kills × 100. Both display two decimal places, with headshot ratio as a percentage. Missing inputs or zero denominators are null internally and N/A in presentation. Clan Info shows Name from ClanName, Members from ClanTroops and Ranking from ClanExpRank. Keep profile, combat and headshot groups separated by blank lines and retain comma-formatted integer counters.

Missing/malformed numeric fields remain null and display N/A. An entirely unusable player detail response fails clearly. Do not substitute search EXP for a missing detail Exp or JSON Rank for the verified HTML game ranking. Names and Markdown are escaped only for display. Identifiers remain internal and never appear in the presentation model or reply.

Accept no matches only when the verified `.nodata_n` message is present with no result rows. Missing/changed required table or identity selectors raise a clear structure error. Login/CAPTCHA responses are explicit access errors.

Never fabricate players/identifiers or present partial lists as complete. Searches have a bounded deduplicated cache using MEMBER_CACHE_TTL_SECONDS and share the optional request spacing/upstream rate-limit gate with clan/detail requests and logo navigation. Local spacing defaults to zero. Actual HTTP 429 / Retry-After pauses still apply. The corrected public page confirms a complete 91-member roster.
